# Security Policy

A6GP is a research protocol and reference runtime. Do not use the in-memory implementation to control production telecom infrastructure.

Security-sensitive invariants include lease-chain validity, tenant isolation, action-hash authorization, replay protection, idempotency, TOCTOU context binding, R3 approval quorum, evidence independence, and UNKNOWN reconciliation.

Please report security issues privately to the repository owner rather than opening a public exploit issue when disclosure could affect a real network or deployment.
